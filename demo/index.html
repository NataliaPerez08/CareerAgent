NovaJobs

A local demo job board for the CareerAgent demo. Each posting is a plain page on purpose — copy the link you need and feed it to /api/v1/jobs/fetch.

  • Junior Backend Engineer (server-rendered)
  • Data Scientist (SPA with embedded JSON)
  • Senior DevOps Engineer (strict requirements)

Serve with python scripts/demo_job_site.py (default port 8001).
